# GAETA Prime Store

Site oficial da GAETA Prime — Apple Premium Store.

## Estrutura

- `index.html` — Home principal
- `iphone.html` — Página de iPhones
- `produto.html` — Template de produto (dinâmico via ?id=)
- `colecao.html` — Coleção/catálogo
- `sobre.html` — Sobre a GAETA Prime
- `contato.html` — Contato e FAQ
- `style.css` — Estilos globais
- `main.js` — JavaScript global
- `vercel.json` — Configuração do Vercel

## Deploy

Conectado ao Vercel. Cada push na branch `main` publica automaticamente.
